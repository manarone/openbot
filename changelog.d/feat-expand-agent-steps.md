### Added

- The activity line of a working agent, such as "Putting the answer together…", now has an arrow.
  Click it to see the agent's thinking and tool steps for the turn so far. A finished answer shows
  the same steps in a closed "Steps" row above it.
- Settings > General has "Show agent steps", which opens the steps by default on this device and
  browser. The web client has the same switch in Preferences.
